# ref_vlsi26_conv_2x1_g300_m60_uniform

Canonical identifier for the VLSI 2026 conventional-HBM paper reference:
two 22 x 11 mm, approximately 0.66 mm-tall 12Hi cubes, GPU power 300 W,
and total HBM power 60 W.

This identifier records the external paper reference only. It is not one of
the six current official experiment configs and has no accepted om3dthermal
solve result. The abandoned run artifact was deleted and is not reused.
